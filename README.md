# FixLens · 고정 카메라 공간 정리 프로토타입

FixLens는 카메라를 고정해 책상 같은 작은 공간을 스캔하고, 정리 스타일을 고른 뒤 물건을 하나씩 옮기도록 안내하는 모바일 웹 프로토타입입니다. **공간 스캔 시작**을 누르면 화면 분석 진행률과 물체 인식 결과가 표시됩니다. 스캔 후 미니멀·작업 효율·아늑하게 중 한 가지 배치 스타일을 고르면 물건별 목표 위치와 화살표 안내를 볼 수 있습니다.

## 동작 방식

1. 브라우저에서 COCO-SSD Lite MobileNet 모델을 Web Worker와 WASM으로 실행해 카메라 장면의 물체를 감지합니다.
2. 12초 동안 장면을 분석하고, 물체별 경계 상자와 이름을 보여줍니다. 사용자는 이름을 고치거나 배치할 물건을 제외할 수 있습니다.
3. 스캔 중 Mac의 Ollama 서버에 장면을 간헐적으로 보내 `qwen3.5:0.8b`가 이름과 감지 후보를 보완합니다. 요청 사이에는 최소 5초 간격을 둡니다.
4. 정리 스타일을 선택하면 화면 좌표 기준으로 물건별 목표 위치를 만들고, 한 물건씩 점선 목표와 화살표로 안내합니다.
5. 안내 중 브라우저가 물건이 목표 위치 근처에 놓였는지 추정합니다. 사용자는 감지 결과를 확인하거나 직접 이동 완료를 눌러 다음 물건으로 넘어갑니다.

물체 감지와 이동 관찰은 휴대폰 브라우저에서 실행됩니다. Mac의 Qwen 모델은 스캔 중 이름 후보를 간헐적으로 보완합니다. 브라우저와 기기 성능에 따라 감지 속도가 달라집니다.

## 현재 범위와 한계

- 화면 강조는 픽셀 단위 외곽선이 아닌 사각 경계 상자입니다. COCO의 일반 물체 범주에 없는 물건이나 작은 물체를 놓치거나 잘못 분류할 수 있습니다.
- 스캔 진행률은 고정된 화면을 분석하는 시간 진행률입니다. 공간이 완벽히 재구성되었거나 카메라가 전체 공간을 덮었음을 뜻하지 않습니다.
- 스타일 배치안은 화면 좌표에 배치하는 프로토타입 규칙입니다. 책상 깊이와 물체 크기, 사용 빈도, 실제 충돌 여부를 계산하는 AI 공간 최적화는 아닙니다.
- 화살표와 목표 위치는 카메라 영상 위의 2D 오버레이입니다. 카메라를 움직이면 안내가 실제 공간에 고정되지 않으므로 스캔부터 이동 완료까지 카메라와 책상을 고정해야 합니다.
- 이동 자동 감지는 인식된 이름과 목표 화면 영역을 비교하는 추정입니다. 손이나 가림, 비슷한 물체, 분류 변화 때문에 틀릴 수 있으며 완료 버튼으로 직접 확인할 수 있습니다.
- 깊이, 카메라 자세, 가려진 물체, 여러 시점 간 정합, 실제 3D 공간은 재구성하지 않습니다.
- 스캔 영상이나 공간 지도를 디스크에 저장하지 않습니다. 이름과 위치는 현재 페이지 세션에서만 사용합니다.

## Mac에서 서버 관리

Finder에서 `FixLens Server.command`를 더블클릭하면 터미널에 관리 메뉴가 열립니다. 처음 실행할 때 macOS가 확인 창을 띄우면 파일을 열도록 허용하세요. 메뉴에서 서버 시작, 상태 확인, 종료, 로컬 화면 열기, 로그 보기와 휴대폰용 HTTPS 터널 관리를 할 수 있습니다.

필요한 것: Node.js 20 이상, Ollama, 그리고 프로젝트의 `dist/`에 포함된 COCO-SSD 및 WASM 모델 파일. Qwen 이름 보완을 쓰려면 모델을 한 번 받아야 합니다.

```sh
ollama pull qwen3.5:0.8b
```

**서버 시작**은 Ollama가 응답하지 않을 때 Ollama를 실행한 뒤 FixLens 웹 서버를 엽니다. Ollama가 이미 실행 중이면 기존 인스턴스를 그대로 사용합니다. 웹 서버는 `http://127.0.0.1:4173`에서 열립니다. Ollama를 사용할 수 없어도 브라우저의 기본 실시간 물체 감지는 동작합니다.

**서버 종료**는 이 메뉴가 직접 시작해 PID를 기록한 프로세스만 종료합니다. 메뉴를 열기 전에 별도로 실행 중이던 서버나 Ollama는 종료하지 않습니다. 실행 로그와 PID 파일은 `.run/`에 저장되며 Git에는 포함되지 않습니다.

## 휴대폰에서 카메라 테스트

휴대폰 브라우저의 카메라는 HTTPS 페이지에서 열어야 합니다. 관리 메뉴에서 **휴대폰용 HTTPS 터널 시작**을 선택하면 됩니다. 이 기능은 `cloudflared`가 설치되어 있고 FixLens 웹 서버가 실행 중일 때 사용할 수 있습니다. 터널은 공개 접속 주소를 만들므로 필요할 때만 켜고, 사용을 마치면 메뉴에서 종료하세요. 터미널 명령으로 직접 실행할 수도 있습니다.

```sh
cloudflared tunnel --url http://127.0.0.1:4173
```

터미널에 표시된 HTTPS 주소를 휴대폰에서 열고 카메라 권한을 허용한 뒤 책상 전체가 보이도록 휴대폰을 고정하고 **공간 스캔 시작**을 누릅니다. Quick Tunnel 주소는 실행을 다시 할 때 바뀌며, Mac과 서버 프로세스가 켜져 있을 때만 사용할 수 있습니다. 주소는 **상태 확인**이나 `.run/tunnel.log`에서도 확인할 수 있습니다.

휴대폰의 실시간 감지 프레임은 기기 안에서 처리합니다. Qwen 이름 보완을 위해 보내는 장면 이미지는 HTTPS 터널을 지나 Mac의 Ollama 서버에 도달하며, 이 앱은 원본 이미지를 저장하지 않습니다. Quick Tunnel은 개발용 공개 주소이므로 링크를 아는 사람이 접속할 수 있습니다.

## 설정

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `4173` | 웹 서버 포트 |
| `FIXLENS_HOST` | `127.0.0.1` | 서버 바인딩 주소 |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | Ollama 서버 주소 |
| `OLLAMA_MODEL` | `qwen3.5:0.8b` | 이름 보완에 사용할 설치된 Ollama 모델 |

서버는 이미지 요청을 JPEG, PNG, WebP 및 최대 2MB, 960×720으로 제한하고 한 번에 하나의 추론 요청만 처리합니다. 브라우저 요청 횟수도 제한합니다.

node --check dist/app.mjs
