# Included model and runtimes

- TensorFlow.js 4.22.0 and WASM backend 4.22.0: https://github.com/tensorflow/tfjs (Apache-2.0).
- COCO-SSD JavaScript package 2.2.3: https://github.com/tensorflow/tfjs-models/tree/master/coco-ssd (Apache-2.0).
- ssdlite_mobilenet_v2 model: https://storage.googleapis.com/tfjs-models/savedmodel/ssdlite_mobilenet_v2/model.json (official TensorFlow.js model distribution).
- License text retained at dist/vendor/LICENSE.txt. Asset checksums are in model-assets.sha256.json.
- Official reference image used for local validation only: https://github.com/tensorflow/tfjs-models/blob/master/coco-ssd/demo/image1.jpg . Not included in the published site.
